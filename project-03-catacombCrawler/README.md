# 🏰 Catacomb Crawler (Java Console Game)

**Catacomb Crawler** is a text-based adventure game in Java where you navigate a dungeon, fight monsters, and try to escape the catacomb alive. This project demonstrates object-oriented programming, user input handling, and simple game mechanics in Java.

---

## 📌 Features

- Navigate a dungeon of variable size (5x5 to 10x10)  
- Fight randomly placed monsters with turn-based combat  
- Track your health and damage  
- Encounter monsters in the same or adjacent rooms  
- Escape the catacomb by reaching the exit at the bottom-right corner  
- Randomized monster placement and damage  

---

## 🛠️ Technologies Used

- Java  
- Console input/output  
- Object-oriented programming with classes (`Actor`, `Main`)  

---
